## Usage

<code>[TypeTheoryRules]()[*name*]</code> gives the rules of the named type theory: `"CalculusOfInductiveConstructions"`, the rules of the prelude, `"MartinLofTypeTheory"`, which has no universe of propositions, or `"CubicalTypeTheory"`, Martin-Löf type theory with the primitives of cubical type theory.

<code>[TypeTheoryRules]()[*name*, *setting* -> *value*, ...]</code> gives those rules with some settings changed.

## Details & Options

- The rules are what the kernel allows and computes; the declarations of an environment are what it assumes. Every environment carries the rules it was started with and checks each declaration and term by them.
- <code>[TypeTheoryEnvironment]()[*rules*]</code> gives the environment with no constants that follows *rules*, the same one each time, and <code>[TypeTheoryEnvironment]()[*rules*, {*declaration1*, ...}]</code> extends it. Every environment made from it follows the same rules, and <code>[Information]()[*env*, "Rules"]</code> gives them.
- <code>*rules*[*setting*]</code> gives the value of a setting. Each setting is [True]() or [False]():

| setting | CalculusOfInductiveConstructions | MartinLofTypeTheory | CubicalTypeTheory |
| --- | --- | --- | --- |
| `"Prop"` | [True]() | [False]() | [False]() |
| `"RewriteRules"` | [False]() | [False]() | [False]() |
| `"Quotients"` | [True]() | [False]() | [False]() |
| `"Quantities"` | [False]() | [False]() | [False]() |
| `"Cubical"` | [False]() | [False]() | [True]() |

- The setting `"Prop"` says whether <code>[TypeUniverse]()[0]</code> is a universe of propositions: impredicative, with proof irrelevance, K-like reduction and elimination of subsingletons into any universe.
- The setting `"RewriteRules"` says whether [TypeTheoryRewriteRule]() declarations may give an axiom computation rules.
- The setting `"Quotients"` says whether [TypeTheoryQuotients]() may declare the quotient types, whose lift computes on a class. The calculus of inductive constructions has them; without them it is the theory of Rocq's kernel. They need Prop.
- The setting `"Quantities"` says whether a binder may have a quantity, the third argument of <code>[Typed]()[*x*, *A*, *q*]</code> or <code>[TypedImplicit]()[*x*, *A*, *q*]</code>: 0, so the code that runs never uses *x*, or 1, so it uses *x* at most once. A binder without one has the quantity [Infinity](). The kernel then counts how many times the value of each definition, the proof of each theorem and each term it checks uses its variables outside its types, and two function types are equal only if their binders have the same quantities. None of the named rules has quantities.
- Rules with quantities only reject more than the same rules without them, so they are consistent whenever those are.
- The setting `"Cubical"` says whether [TypeTheoryCubical]() may declare the interval, paths, transport, composition and Glue types of cubical type theory. It needs no Prop and no quantities. <code>[TypeTheoryRules]()["CubicalTypeTheory"]</code> is Martin-Löf type theory with it, the rules of <code>[TypeTheoryEnvironment]()["Cubical"]</code>.
- Without Prop, every universe level must be at least 1 whatever its universe parameters are: <code>[TypeUniverse]()[*u* + 1]</code>, which shows as `Type u`, not <code>[TypeUniverse]()[*u*]</code>. A recursor then eliminates into `Type u`, and a theorem may state any type.
- Without Prop, no two proofs of an equality are made equal, which univalence needs: <code>[TypeTheoryEnvironment]()["HomotopyTypeTheory"]</code> follows `"MartinLofTypeTheory"` with rewrite rules.
- Recursors are generated by the rules, so the declarations [Normal]() gives rebuild an environment under its own rules but need not check under others; [TypeTheoryTranslate]() moves an environment to other rules.

## Basic Examples

The rules of the prelude, the calculus of inductive constructions:

```wl
Information[TypeTheoryEnvironment["Prelude"], "Rules"]
```

```wl
TypeTheoryRules["MartinLofTypeTheory"]["Prop"]
```

```wl
Information[TypeTheoryEnvironment["HomotopyTypeTheory"], "Rules"] === TypeTheoryRules["MartinLofTypeTheory", "RewriteRules" -> True]
```

## Scope

The settings of the calculus of inductive constructions, those of Lean's kernel:

```wl
TypeTheoryRules["CalculusOfInductiveConstructions"] /@ {"Prop", "Quotients", "RewriteRules", "Quantities", "Cubical"}
```

<!-- => {True, True, False, False, False} -->

```wl
TypeTheoryRules["CubicalTypeTheory"]
```

---

An environment of Martin-Löf type theory, where a theorem may state a type:

```wl
units = TypeTheoryEnvironment[TypeTheoryRules["MartinLofTypeTheory"], {
    TypeTheoryInductiveType[Unit, TypeUniverse[1], {UnitIntroduction -> Unit}],
    TypeTheoryTheorem[UnitInhabited, Unit, UnitIntroduction]
}]
```

```wl
units[UnitInhabited]
```

```wl
TypeTheoryType[InductiveRecursor[Unit], units]
```

```wl
TypeTheoryType[Equal]
```

## Options

### Prop

With Prop, a statement about every proposition is a proposition: Prop is impredicative.

```wl
TypeTheoryType[ForAll[{Typed[p, TypeUniverse[0]]}, p]]
```

<!-- => Prop -->

Without Prop every universe is predicative, and a statement about every type lives in a higher universe:

```wl
TypeTheoryType[ForAll[{Typed[A, TypeUniverse[1]]}, A], "HomotopyTypeTheory"]
```

<!-- => Type 1 -->

---

With Prop, any two proofs of a proposition are equal by computation, so reflexivity proves them equal:

```wl
TypeTheoryCheck[
    TypeTheoryTerm[{p, q} |-> "equalityReflexivity"[p]],
    TypeTheoryTerm[ForAll[{Typed[p, 2 + 2 == 4], Typed[q, 2 + 2 == 4]}, p == q]]
]
```

<!-- => Success["TypeChecked", ...] -->

Without Prop, two paths from the base point of the circle to itself are not equal by computation:

```wl
TypeTheoryCheck[
    TypeTheoryTerm[{p, q} |-> "equalityReflexivity"[p], "HomotopyTypeTheory"],
    TypeTheoryTerm[ForAll[{Typed[p, "circleBase" == "circleBase"], Typed[q, "circleBase" == "circleBase"]}, p == q], "HomotopyTypeTheory"]
]
```

<!-- => Failure["TypeMismatch", ...] -->

### RewriteRules

Rules that allow rewrite rules, and an axiom that flips bits by two of them:

```wl
bits = TypeTheoryEnvironment[TypeTheoryRules["MartinLofTypeTheory", "RewriteRules" -> True], {
    TypeTheoryInductiveType[Bit, TypeUniverse[1], {BitZero -> Bit, BitOne -> Bit}],
    TypeTheoryAxiom[Flip, TypeSpecifier[{Bit} -> Bit]],
    TypeTheoryRewriteRule[FlipZero, Flip[BitZero] -> BitOne],
    TypeTheoryRewriteRule[FlipOne, Flip[BitOne] -> BitZero]
}]
```

<!-- => TypeTheoryEnvironment summary box: 7 constants -->

The axiom computes:

```wl
WeakHeadNormalForm[TypeTheoryTerm[Flip[Flip[BitZero]], bits]]
```

<!-- => BitZero -->

### Quotients

Without quotients, the calculus of inductive constructions is the theory of Rocq's kernel, which has no quotient types of its own:

```wl
TypeTheoryEnvironment[TypeTheoryRules["CalculusOfInductiveConstructions", "Quotients" -> False], {
    TypeTheoryInductiveType[Equal, ForAll[{TypedImplicit[A, TypeUniverse[u]], Typed[x, A], Typed[y, A]}, TypeUniverse[0]], {
        "equalityReflexivity" -> ForAll[{TypedImplicit[A, TypeUniverse[u]], Typed[x, A]}, x == x]
    }],
    TypeTheoryQuotients[]
}]
```

<!-- => Failure["QuotientsNotAllowed", ...] -->

### Quantities

Under rules with quantities, a function whose argument has the quantity 1 may use it once:

```wl
TypeTheoryEnvironment[TypeTheoryRules["CalculusOfInductiveConstructions", "Quantities" -> True], {
    TypeTheoryDefinition[ApplyOnce, {TypedImplicit[A, TypeUniverse[1], 0], Typed[f, TypeSpecifier[{A} -> A], 1], Typed[x, A]} |-> f[x]]
}]
```

<!-- => TypeTheoryEnvironment summary box: 1 constants -->

But not twice:

```wl
TypeTheoryEnvironment[TypeTheoryRules["CalculusOfInductiveConstructions", "Quantities" -> True], {
    TypeTheoryDefinition[ApplyTwice, {TypedImplicit[A, TypeUniverse[1], 0], Typed[f, TypeSpecifier[{A} -> A], 1], Typed[x, A]} |-> f[f[x]]]
}]
```

<!-- => Failure["QuantityExceeded", ...] -->

---

Under rules without quantities, the prelude's among them, a binder may not have one:

```wl
TypeTheoryEnvironment[{TypeTheoryDefinition[AffineIdentity, Typed[n, NonNegativeIntegers, 1] |-> n]}]
```

<!-- => Failure["QuantitiesNotAllowed", ...] -->

### Cubical

The cubical primitives need cubical rules, here with a dependent sum declared first:

```wl
TypeTheoryEnvironment[TypeTheoryRules["CubicalTypeTheory"], {
    TypeTheoryInductiveType[DependentSum, ForAll[{Typed[A, TypeUniverse[u + 1]], Typed[B, TypeSpecifier[{A} -> TypeUniverse[v + 1]]]}, TypeUniverse[Max[u + 1, v + 1]]], {
        "dependentPair" -> ForAll[{TypedImplicit[A, TypeUniverse[u + 1]], TypedImplicit[B, TypeSpecifier[{A} -> TypeUniverse[v + 1]]], Typed[a, A], Typed[b, B[a]]}, DependentSum[A, B]]
    }],
    TypeTheoryCubical[DependentSum]
}]
```

<!-- => TypeTheoryEnvironment summary box: 15 constants -->

An environment made from rules:

```wl
units = TypeTheoryEnvironment[TypeTheoryRules["MartinLofTypeTheory"], {TypeTheoryInductiveType[Unit, TypeUniverse[1], {UnitIntroduction -> Unit}]}]
```

```wl
Information[units, "Rules"] === TypeTheoryRules["MartinLofTypeTheory"]
```

## Possible Issues

Without Prop, no universe may be Prop, for any value of its universe parameters:

```wl
TypeTheoryEnvironment[TypeTheoryRules["MartinLofTypeTheory"], {TypeTheoryAxiom[AnySort, TypeUniverse[u]]}]
```

<!-- => Failure["NoProp", ...] -->

---

Under the rules of the prelude, a theorem must state a proposition:

```wl
TypeTheoryEnvironment[TypeTheoryEnvironment[], {
    TypeTheoryInductiveType[Unit, TypeUniverse[1], {UnitIntroduction -> Unit}],
    TypeTheoryTheorem[UnitInhabited, Unit, UnitIntroduction]
}]
```

<!-- => Failure["PropositionExpected", ...] -->

---

The declarations of the prelude need Prop, so they do not rebuild under Martin-Löf type theory; [TypeTheoryTranslate]() moves them instead:

```wl
TypeTheoryEnvironment[TypeTheoryRules["MartinLofTypeTheory"], Normal[TypeTheoryEnvironment["Prelude"]]]
```

<!-- => Failure["NoProp", ...] -->

---

A name of no type theory gives a [Failure]() that lists the names there are:

```wl
TypeTheoryRules["Lean"]
```

<!-- => Failure["UnknownRules", ...] -->

---

So does a setting the rules do not have, or a value that is not [True]() or [False]():

```wl
TypeTheoryRules["MartinLofTypeTheory", "Univalence" -> True]
```

<!-- => Failure["InvalidRuleSetting", ...] -->
